## 3. How to Use the Central Dashboard

1. Double-click or open [`INDUS-EMAIL-TEMPLATE-LIBRARY/index.html`](index.html) in any web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari).
2. **Search**: Type an email ID (e.g. `INDUS-EMAIL-042`), product line (e.g. `cycloidal`), or industrial role into the search box.
3. **Filter**: Click category tabs or filter by target audience.
4. **Interactive Modal Preview**:
   - Click **Preview** on any card to load the template into an interactive iframe.
   - Switch between **Desktop (640px)** and **Mobile (375px)** viewport modes.
   - Click **Copy Subject Line**, **Copy Preview Text**, or **Copy Full HTML** to quickly paste into email automation platforms (HubSpot, Mailchimp, Marketo, Pardot).
   - Click **Open in New Tab** to view the standalone `.html` file.
